# REST API z JSON

- Status: Sprejeto
- Datum: 2026-10-22

## Kontekst in problem

Frontend potrebuje podatke o projektih in nalogah; kasneje je predvidena mobilna aplikacija.

## Obravnavane alternative

- REST API.
- GraphQL.
- Neposredno strežniško izrisovanje.

## Sprejeta odločitev in utemeljitev

Izberemo **REST API**. Jasne končne točke omogočajo ločen razvoj in kasnejšo uporabo API-ja na mobilni napravi.

## Posledice

### Pozitivne
- Ponovna uporaba API-ja.
- Ločena frontend in backend.

### Negativne
- Potrebno je vzdrževati API pogodbe.
- Nekateri pogledi zahtevajo več zahtevkov.
