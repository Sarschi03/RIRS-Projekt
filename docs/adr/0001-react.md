# React za uporabniški vmesnik

- Status: Sprejeto
- Datum: 2026-10-22

## Kontekst in problem

Kanban tabla, časovnik in dnevni seznam zahtevajo interaktivno posodabljanje brez osveževanja strani.

## Obravnavane alternative

- React z Vite
- Vue
- Strežniške HTML predloge

## Sprejeta odločitev in utemeljitev

Izberemo **React z Vite**. Komponente kartic nalog in obrazcev lahko ponovno uporabimo na več zaslonih.

## Posledice

### Pozitivne
- Ponovna uporaba komponent.
- Hiter razvoj interaktivnih pogledov.

### Negativne
- Potrebno je upravljanje stanja.
- Ločen postopek gradnje frontenda.
