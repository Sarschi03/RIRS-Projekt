# node-postgres za dostop do baze

- Status: Sprejeto
- Datum: 2026-10-22

## Kontekst in problem

Backend potrebuje SQL povezave med projekti, nalogami in časovnimi vnosi.

## Obravnavane alternative

- node-postgres (pg)
- Prisma ORM
- Drizzle ORM

## Sprejeta odločitev in utemeljitev

Izberemo **node-postgres (pg)**. Neposredne parametrizirane SQL poizvedbe dajejo nadzor nad JOIN in SUM poizvedbami brez ORM.

## Posledice

### Pozitivne
- Nadzor nad SQL.
- Brez dodatnega ORM sloja.

### Negativne
- Več ročnega SQL.
- Ročno preslikavanje rezultatov in migracije.
